# StudyPlanner

个人学习计划工具，纯 HTML、CSS 和 JavaScript，无需安装依赖或构建。

**数据保存在当前浏览器中，不会上传服务器。请定期导出备份。**

## 运行与 GitHub Pages

可以直接打开 `index.html`，也可以将本文件夹的内容上传至 GitHub 仓库。

发布 GitHub Pages 时，将 `index.html`、`app.js`、`styles.css`、`seed-data.js` 放在仓库根目录。在仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**，指定 `main` 分支和 `/(root)` 目录并保存。部署完成后，通过 Pages 提供的网址访问。

上传的是本文件夹内的文件；不要把整个文件夹再嵌套在仓库根目录，否则访问路径也需要加上文件夹名称。

[GitHub Pages 官方部署说明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)

## 演示数据

首次打开载入 9 个虚构时间块，涵盖固定课程、学习计划、完成记录和拖欠任务。示例日期按首次打开时的当前星期生成，之后刷新不会重新排期。

演示科目为编程、阅读、设计和示例课程。演示学习上限为每天 2 小时，可在设置中自行修改。这里没有真实课表、个人学习笔记、错题、薄弱点或个人排期迁移脚本。

## 功能

- 周日历：同时查看 3 天或 7 天，支持前置今天、连续翻页、跨日拖动和时长调整。
- 时间块：固定课程、学习计划、完成状态和学习记录；支持单次及重复计划。
- 拖欠区：未完成计划可暂存并重新拖回日历，按时长显示高度，支持排序。
- 管理科目：添加、删除；删除前确认，可保留关联时间块并改为“未分类”，或级联删除。
- 周目标、科目统计、周回顾及按周或月查看的学习时长柱状图。
- 按重要性生成间隔复习；搜索、筛选及撤销操作。
- 每日学习上限及超时提醒。
- 完整 JSON 备份与恢复、CSV 导出、ICS 日历导出。

## 保存与备份

数据使用当前浏览器的 `localStorage` 保存。公开版使用独立的 `studyPlanner.public.*` 存储键，不读取私人版的数据。

不同浏览器、设备、网址以及本地文件和 GitHub Pages 之间不会自动同步。清理网站数据或使用无痕窗口可能导致数据丢失或不保留。请通过 **设置 → 导出完整备份** 保存 JSON，需要时再导入。

私人版仍单独保留。请在私人版页面导出真实数据，并将备份放在此公开文件夹与 Git 仓库之外。不要把个人 JSON、CSV、ICS 备份上传到公开仓库；`.gitignore` 只是辅助防止误加入，网页手动上传时仍需检查所选文件。

本项目不包含账号、服务器或云同步，也不会自动发送学习数据。访问部署后的页面时仍需加载网站文件；下载本文件夹后可以离线打开使用。

## 文件

- `index.html`：页面入口。
- `styles.css`：样式。
- `app.js`：交互和浏览器存储。
- `seed-data.js`：少量虚构演示数据。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。
- `.gitignore`：排除常见备份及临时文件。
